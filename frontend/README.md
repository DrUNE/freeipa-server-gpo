# Frontend (GPUI editor)

ES-module sources in `src/`, built with **Vite** into one committed bundle:
`../plugin/ui/grouppolicy/js/app.js` (UMD; registers as an AMD module under FreeIPA's RequireJS and
depends on its `freeipa/ipa` and `freeipa/rpc`). The RPM installs the committed bundle, so Node is
not needed to build the package. `chain.js`, `gpo.js`, `css/` and `img/` live in `../plugin/ui/grouppolicy/` as before;
`gpo.js` and `chain.js` take `translations` and `editorDialog` from the bundle (`js/app`).

Node is managed with fnm: `eval "$(fnm env)"` (or `fnm use`), Node >= 20.

## Commands (from the repository root)

| Command | Purpose |
|---|---|
| `make ui-dev-install` | `npm install` in `frontend/` |
| `make ui-dev` | Vite dev stand at http://127.0.0.1:8765/ipa/ui/ (`?gpo=Name&lang=ru`), no FreeIPA needed |
| `make ui-build` | Rebuild the committed bundle (`npm run build`) |
| `make ui-build-check` | Fail if the committed bundle differs from a fresh build |
| `make ui-lint` | ESLint (`eslint.config.mjs`) |
| `npm run typecheck` (in `frontend/`) | `tsc --noEmit` over all of `src/` (JSDoc, `checkJs`, non-strict). `types/globals.d.ts` models the editor's ad-hoc members as open records; 29 spots carry `// @ts-expect-error TODO(types)` and should be replaced by precise types |

Workflow: edit `src/`, check in the dev stand (reloads on save), run `make test-ui`, run `make ui-build`,
commit `src/` together with the rebuilt `js/app.js`.

## Dev stand (`dev/`)

Vite serves `src/` directly. `freeipa/ipa` and `freeipa/rpc` resolve to ES shims in `dev/shims/`;
`vite.config.mjs` answers `POST /ipa/session/json` from the mock backend `dev/backend.cjs` and serves the plugin's
`css/` and `img/` under `/ipa/ui/js/plugins/chain/`. See `dev/README.md`. `chain.js` and `gpo.js` do not run in the stand
(they need FreeIPA's own modules); check them on a live server (`.devcontainer/`).

## Tests

Two npm tasks (both available as make targets):

| Task | Make | What it runs |
|---|---|---|
| `npm test` | `make test-ui` | `tests/unit` and `tests/integration` against mocks; no FreeIPA needed |
| `npm run test:ipa` | `make test-ui-ipa` | `tests/e2e` against a real FreeIPA server in the podman dev container |

Layout of `tests/` (CommonJS, `node:test`; Playwright for browser tests):

- `unit/` — read `src/` directly. `scripts/read-amd.cjs` presents an ES module as
  `define([deps], function (deps) {...})`, so tests keep injecting mocked dependencies.
- `integration/` (`*.browser.test.js`) — real Chromium and DOM, RPC mocked. They run against
  `frontend/.test-root/` (git-ignored, regenerated by `npm test`): each `src` module as its own AMD
  module plus symlinks to `css/`, `img/`, `chain.js`, `gpo.js`. `bundle.browser.test.js` loads the
  committed production bundle through RequireJS instead.
- `e2e/` — logs in to the real Web UI, checks menus and facets, creates a GPO through the container's
  `ipa` CLI, opens the editor from the GPO page and removes the GPO again.

`npm run test:ipa` first runs `scripts/ipa-up.sh`: starts the container `freeipa-gpo-dev` if stopped and
re-runs `.devcontainer/scripts/setup-ipa.sh` (binds the workspace sources, restarts httpd). It needs
`.devcontainer/host-setup.sh` run once and the container created once from VS Code. With `REQUIRE_IPA=1`
(set by the task) an unreachable server fails instead of skipping. Settings: `IPA_URL`, `IPA_ADMIN_USER`,
`IPA_ADMIN_PASSWORD`, `IPA_CONTAINER`.

Install Chromium once: `npx playwright install chromium` (in `frontend/`).

## CI

Job `frontend` in `.forgejo/workflows/python-backend.yml`: `npm ci`, lint, `build:check`, Chromium, UI tests. Tests that need the native admix binding, FreeIPA's jQuery or a live server are skipped there.
